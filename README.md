📌 Project Overview

This project analyzes digital marketing funnel performance to understand how users move from:

Visits → Leads → Customers

The dashboard helps identify:

Channel performance

Conversion drop-offs

Customer acquisition efficiency

Country-wise marketing results

Traffic trends over time

Built using Power BI, this solution provides interactive and data-driven insights for marketing optimization.

🎯 Objectives

Track website visits

Measure lead generation

Calculate customer conversions

Identify best marketing channels

Analyze country/device performance

Improve marketing ROI
